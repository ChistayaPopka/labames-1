# Кнопка и картинка на двух ноутбуках

Оба ноутбука должны быть в одной сети Wi-Fi. Python на них не нужен — есть готовые exe в папке `dist`.

1. **Ноутбук с картинкой:** скопируйте `Картинка.exe` и папку `images` (рядом с exe), запустите `Картинка.exe`.
   Внизу окна будет написан IP.
   Когда Windows спросит про брандмауэр, нажмите «Разрешить» (частная сеть).
2. **Ноутбук с кнопкой:** скопируйте `Кнопка.exe`, запустите, введите этот IP и нажмите кнопку (или пробел).

Свои картинки (PNG, JPG, GIF, BMP, WEBP) кладите в папку `images` рядом с `Картинка.exe`.
Если папка пустая, показываются встроенные картинки.

На ноутбуке с картинкой F11 включает полный экран, Esc выключает его.

## Пересобрать exe

Нужен Python 3 и `pip install pyinstaller pillow`. Двойной клик по `build.bat` (или `python build.py`) —
он заново рисует иконки (`make_icons.py` → папка `icons`) и собирает оба exe в `dist`.

Без сборки можно запускать и так: `python display.py` и `python button.py`.
