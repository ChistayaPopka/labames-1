# Кнопка и картинка на двух ноутбуках

Нужен Python 3. Оба ноутбука должны быть в одной сети Wi-Fi.

1. Скопируйте папку на оба ноутбука.
2. **Ноутбук с картинкой:** `python display.py`. Внизу окна будет написан IP, например `192.168.1.42`.
   Когда Windows спросит про брандмауэр, нажмите «Разрешить» (частная сеть).
3. **Ноутбук с кнопкой:** `python button.py`, введите этот IP и нажмите кнопку (или пробел).

Свои картинки кладите в папку `images` на ноутбуке с картинкой (PNG или GIF).
Чтобы работали JPG и картинки подгонялись под размер окна: `pip install pillow`.
Если папка пустая, показываются встроенные картинки.

На ноутбуке с картинкой F11 включает полный экран, Esc выключает его.
